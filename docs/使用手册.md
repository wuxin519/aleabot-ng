# AleaBot NG 使用手册

> 面向跑团主（DM/KP）与玩家的完整操作说明。

---

## 一、5 分钟接上 QQ

### 1. 准备 OneBot 框架

推荐 **NapCat**（基于 QQNT，维护活跃）：

1. 在跑机器人的电脑/服务器上安装 NapCat
2. 首次启动后用手机 QQ 登录（这一步由 NapCat 负责，**只需一次**，之后自动登录）
3. 打开 NapCat 配置，启用 **WebSocket 服务**：
   - 正向 WebSocket：监听端口 `3001`（默认）
   - 若设置了 `token`，记下来备用

> ⚠️ 不要用 oicq / go-cqhttp 这类已停更或需逆向登录的方案——二维码会频繁失效、随时可能封号。

### 2. 配置 AleaBot

编辑 `<安装目录>/.env`：

```env
ONEBOT_ENABLED=true
ONEBOT_WS_URL=ws://127.0.0.1:3001
ONEBOT_TOKEN=            # 有就填，没有留空
```

### 3. 重启并验证

```bash
sudo systemctl restart aleabot
tail -f <安装目录>/logs/bot.log
```

看到 `[adapter] qq 已连接 QQ:你的QQ号` 即成功。

### 4. 群里测试

把机器人拉进群，发送 `.r 3d6+2`，收到回复即大功告成 🎉

## 二、接上 KOOK

1. 打开 [KOOK 开发者中心](https://developer.kookapp.cn/) → 创建应用 → 创建机器人
2. 在「机器人」页面复制 **Token**
3. 在「邀请链接」页面生成邀请链接，把机器人加进你的服务器
4. 编辑 `.env`：

```env
KOOK_ENABLED=true
KOOK_TOKEN=你的Token
```

5. `sudo systemctl restart aleabot`，日志出现 `[adapter] kook 已连接` 即成功

> QQ 与 KOOK 可以**同时启用**，两者数据存在同一数据库但完全隔离，互不干扰。

## 三、指令详解

### 3.1 掷骰

| 指令 | 说明 |
|------|------|
| `.r 3d6` | 掷 3 个六面骰 |
| `.r 3d6+2` | 掷骰后 +2 |
| `.r 2d8-1` | 掷骰后 -1 |
| `.r 4d6k3` | 掷 4 个 d6，取最高的 3 个（D&D 属性生成） |
| `.r 4d6dl1` | 掷 4 个 d6，去掉最低的 1 个 |
| `.r 2d20kh1` | 优势（2d20 取高） |
| `.r 2d20kl1` | 劣势（2d20 取低） |
| `.r 1d100<=50` | COC 检定（输出成功等级） |
| `.r` | 掷群默认骰（默认 1d100） |
| `.r3d100` | **紧贴写法**（≡ `.r 3d100`，`.ra侦查60`、`.st力量88` 同理） |
| `.r 3#2d50` | **多轮掷骰**：掷 3 次并给合计（上限 20 轮） |
| `.r d` / `.r 2d` | **省略面数**：用群默认骰面 |
| `.r d20优势` / `.r d劣势` | **中文优势/劣势**（= 2d20kh1 / 2d100kl1） |
| `.r f` | **Fate 命运骰**：4 枚 [-1/0/+1] |
| `.r 5a6` | **WoD 无限骰**：≥6 加骰、≥8 成功 |
| `.r 4c3` | **双十字骰**：≥3 暴击续轮 |
| `.r b3` | **裸奖励骰**（p = 惩罚骰，不做技能检定） |
| `.rh 1d20` | **暗骰**：群里只提示，结果私聊 |

**输出示例**
```
🎲 【张三】3d6+2 = 14
3d6[4+3+5] +2 = 14
```

### 3.2 COC 检定

```
.ra 侦查 60        # 指定目标值
.ra 侦查           # 自动读取你角色卡上的「侦查」技能值
.ra 60             # 直接检定 60
```

**输出示例**
```
✅ 【张三】侦查检定: 1d100 = 23 / 60 → 困难成功
```

成功等级：大成功（1）/ 极难成功（≤目标/5）/ 困难成功（≤目标/2）/ 成功 / 失败 / 大失败

**理智检定 / 对抗检定 / 房规（v1.2 新增）**

```
.sc              # 理智检定（默认成功扣1 / 失败扣1d6，自动写回卡）
.sc 0/1d10       # 成功扣 0 / 失败扣 1d10；.sc 60 1/1d6 直接指定 SAN
.rav @李四 侦查  # 对抗检定：等级高者胜，同级比骰值小
.setcoc 2        # 切换房规（0 默认 / 1 保守 / 2 宽松），.setcoc 查看
```

### 3.3 角色卡

```
.coc              # 生成一张 COC 7 版角色卡（覆盖当前卡）
.coc 5            # 批量掷 5 组主属性（只主属性，技能自定，不写卡）
.coc5 5 / .dnd 4  # 同上，COC5 版 / D&D 版
.dnd              # 生成一张 D&D 5e 角色卡
.st show          # 查看完整角色卡
.st show 侦查      # 只看某一项
.st 力量 88       # 修改属性
.st 力量88        # 紧贴写法（≡ .st 力量 88）
.st name 张三     # 设置角色卡名字（同时是 bot 称呼你的昵称）
.sn / .nn 张三    # 同上，简写
.st hp+1          # 属性增减（+1d4 这类掷骰式也行）
.st 力量          # 查询单个属性
.st del 幸运 魔法  # 删除指定属性
.st clr           # 清空所有属性
.st export        # 导出属性（可直接复制到别的骰子）
.st &手枪伤害=1d6+1  # 保存表达式，之后 .r 手枪伤害 调用
.hp               # 查看 HP；.hp+3 / .hp-1d4 / .hp 50 增减与设值
.san-1d4          # SAN 增减（与 .hp 同一套语法）
```

> 💡 所有指令都支持「紧贴写法」省略动词与参数间的空格，例如 `.boton` ≡ `.bot on`、`.sn张三` ≡ `.st name 张三`、`.initadd张三 15` ≡ `.init add 张三 15`。

### 3.3.1 批量掷主属性（`.coc 5`）

跑团群里常见「天命 5 选 1」「先掷几组再挑」，`.coc N` 就是干这个的：

```
.coc 5        # 一次掷 5 组 COC 7 版主属性
.coc5 5       # COC 5 版（天命）
.dnd 4        # D&D 5e
```

输出**只含主属性 + HP + 总值**，不含技能与衍生值，也**不会写进角色卡**（纯给你挑）。
最多 20 组。挑好一组后用下面的批量/位置录入写进卡里。

### 3.4 快速录入（不用一条条发）

录卡最烦的是一条条发，`.st` 支持一条消息录多个值。

```
.st 力量88 体质70 敏捷60      # 键值批量，空格可省
.st力量88体质70敏捷60         # 上面这条的免空格写法，效果一样
.st 88 70 60 75 80 65 70 60 55   # 按位置录入，免键名
```

**按位置录入的顺序**（与 `.st show` 显示顺序一致）：

| 系统 | 顺序 | 最多几个 |
|------|------|---------|
| COC 7 版 | 力量 体质 敏捷 外貌 意志 体型 智力 教育 幸运 | 9 |
| COC 5 版 | 力量 体质 体型 敏捷 外貌 智力 意志 教育 幸运 | 9 |
| D&D 5e | 力量 敏捷 体质 智力 感知 魅力 | 6 |

> 可以只给前几个（不必给满），超出会提示改用键名写法。

### 3.5 多张角色卡

一个玩家可以同时维护多张卡，随时切换。

```
.st new 调查员A     # 新建一张并自动切过去
.st list            # 列出全部卡（* 是当前卡）
.st switch 调查员A   # 按名字切
.st switch 2        # 按编号切
.pc del 调查员A     # 删掉（v1.4 起删卡用 .pc del）
.pc list            # 卡片管理（.pc new/tag/list/show/nn）
```

> `.ra` / `.sc` / `.hp` 等检定都读**当前卡**。切完卡建议 `.st show` 确认一下数值。
> `.st name` 设的昵称跟着**玩家**走，所有卡通用；`.coc` / `.dnd` 重新生成只覆盖当前卡。
> ⚠️ `.st del` 现在是**删属性**（主流骰娘语义），删角色卡请用 `.pc del`。

### 3.5.1 检定增强（主流骰娘同款）

```
.ra 侦查+10         # 属性调整（-5、+1d4 都行）
.ra 困难侦查         # 难度前缀：困难=÷2、极难=÷5、大成功
.rc 侦查            # 规则书检定（无视群房规，.ra 走房规）
.en 侦查 聆听        # 一次成长多个技能
.en 侦查 +0/1d6     # 自定义成长点数（失败不涨/成功涨 1d6）
.sc 1/1d6 --cap=3   # 理智损失上限（习惯恐怖）
.sc 1/1d6 --half    # 理智损失减半（神话淬炼），可与 --cap 同用
.setcoc details     # 查看全部房规（0-5 / dg）
```

### 3.6 先攻

```
.init add 张三 15   # 加入先攻（同名会覆盖）
.init list          # 查看当前先攻顺序
.init clr           # 清空
```

**输出示例**
```
📋 先攻顺序:
1. 李四 — 20
2. 张三 — 15
```

### 3.7 群配置（管理员）

```
.set prefix !          # 把指令前缀从 . 改成 !
.set defaultDice 1d20  # 改默认骰
.bot off               # 停用本群骰子（停用后只响应 .bot on）
.bot on                # 重新启用
.bot bye               # 让骰子退出本群
```

> 管理员需在 `.env` 的 `ADMIN_IDS` 里配置，多个用逗号分隔；
> **不配置则 `.bot` 开关不限权限**（防止功能被锁死）。

### 3.8 奖励骰 / 惩罚骰 / 多列检定

```
.rb 侦查 60     # 奖励骰检定（十位骰取小，更容易成功）
.rp 侦查 60     # 惩罚骰检定（十位骰取大，更容易失败）
.ra 3#p手枪     # 连开 3 枪，每枪带 1 个惩罚骰（b = 奖励骰，数字为骰数）
```

### 3.9 成长与疯狂

```
.en 侦查        # 成长检定：1d100 > 当前值则 +1d10 并写回角色卡
.en 侦查 65     # 直接指定当前值 65
.ti             # 临时性疯狂表（1d10）
.li             # 长期性疯狂表（1d10）
```

### 3.10 抽牌 / 随机名字 / 重排

```
.drawlist           # 可用牌堆：塔罗 / 扑克
.draw 塔罗 3        # 抽 3 张塔罗，附正逆位
.draw 扑克 5        # 抽 5 张扑克（不放回）
.name cn 10         # 10 个中文名；en = 英文、jp = 日文
.who 甲 乙 丙       # 随机打乱顺序（也支持逗号 / 顿号分隔）
```

### 3.11 统计与娱乐

```
.stat              # 本群掷骰统计（次数、区间分布、掷骰最多的人）
.stat 今日          # 只看今天
.hiy               # 我的掷骰统计（跨群汇总）
.jrrp              # 今日人品（同一天同一人结果固定，刷不出来）
.gugu              # 咕咕咕
.coin 3            # 抛硬币 ×3（正反面统计）
```

### 3.12 跑团日志

```
.log new 黑圣杯     # 新建日志并开始记录（群里发言自动入库）
.log off            # 暂停记录
.log on             # 继续记录
.log end            # 结束，机器人把 txt 文件发到群里
.log end json       # 结束并导出主流骰娘染色器 JSON
.log get            # 导出当前/最后一场（不结束）
.log list           # 本群日志列表
.log stat           # 当前日志统计
.ob                 # 观众模式：你的发言全部标 [OB]，复盘时一键剔除
```

> 记录只发生在**群里**，图片 / 表情 / @ / 语音都会保留成 `[图] [表情] @名字 [语音]`；
> 以 `( （ 【` 开头的发言记为「场外」。
> 完整规则见 `docs/机器人操作全手册.md` 第八章。

## 四、网页管理后台

浏览器打开 `http://<主机IP>:8787/`。

若 `.env` 中设置了 `ADMIN_TOKEN`，需带口令访问：`http://<主机IP>:8787/?token=你的口令`。

| 页面 | 功能 |
|------|------|
| **概览** | 平台在线状态、总掷骰次数、活跃群/用户数、最近备份时间、运行时长 |
| **掷骰日志** | 按平台/关键词筛选，分页查看全部历史记录 |
| **角色卡** | 查看所有用户角色卡及属性摘要，支持删除 |
| **群配置** | 查看/修改各群的指令前缀、默认骰 |
| **数据备份** | 立即备份、下载快照、导出 JSON |

后台每 15 秒自动刷新状态。

## 五、数据与备份

### 文件位置

| 内容 | 路径 |
|------|------|
| 数据库 | `<安装目录>/data/aleabot.db` |
| 备份 | `<安装目录>/data/backups/aleabot-backup-<时间>.db` |
| 日志 | `<安装目录>/logs/bot.log` |

### 备份机制

- **自动**：默认每 24 小时一次，保留最近 14 份（`.env` 可调）
- **退出保护**：服务停止前自动备份一次
- **手动**：后台点「立即备份」，或群内 `.bak`

### 恢复数据

```bash
sudo systemctl stop aleabot
sudo cp <安装目录>/data/backups/aleabot-backup-2026-10-02T12-00-00-000Z.db \
        <安装目录>/data/aleabot.db
sudo rm -f <安装目录>/data/aleabot.db-wal <安装目录>/data/aleabot.db-shm
sudo systemctl start aleabot
```

### 迁移到新机器

1. 拷走 `data/aleabot.db`（或任一份备份）
2. 在新机器按「部署」章节装好程序
3. 把 db 放到 `data/aleabot.db`
4. 改好 `.env` 启动即可

## 七、常见问题

**Q: 机器人不回复？**
1. 查日志 `tail -f <安装目录>/logs/bot.log` 是否有 `已连接`
2. QQ 侧：确认 NapCat 的 WS 服务开着、端口一致、token 正确
3. KOOK 侧：确认 Token 正确、机器人已被加入当前频道
4. 确认群没被禁用、前缀没被改（默认 `.`，用 `.set prefix` 可查后台）

**Q: QQ 连接总断开？**
NapCat 与 AleaBot 之间的 WS 断开会自动重连（指数退避）。若频繁断，检查两者是否在同一台机器、防火墙是否放行 3001。

**Q: 掷骰结果不对？**
表达式语法见上表。注意 `4d6k3` 是"取高 3 个"，`4d6dl1` 是"去低 1 个"，两者结果相同但写法不同。

**Q: 数据存在哪？会丢吗？**
存在 `<安装目录>/data/aleabot.db`。有自动备份 + 退出备份双重保护，备份在 `data/backups/`。

**Q: 怎么改端口？**
`.env` 中 `WEB_PORT=8787`，改完重启。

**Q: 忘记管理口令？**
查看 `<安装目录>/.env` 的 `ADMIN_TOKEN`，或删掉该行清空口令（不建议公网环境这么做）。

## 八、二次开发

```bash
cd <安装目录>
# 修改 src/ 下的 TypeScript 源码（全程中文注释）
npx tsc -p tsconfig.json     # 重新编译
sudo systemctl restart aleabot
```

**项目结构**
```
src/core/       核心引擎（骰点/命令/角色卡/数据/备份）—— 与平台无关
src/platforms/  平台适配器（QQ OneBot / KOOK）—— 新增平台只需实现 PlatformAdapter 接口
src/web/        管理后台 API
public/         管理后台页面（纯 HTML/CSS/JS，无构建）
```

**新增一个平台**：在 `src/platforms/` 下新建文件，实现 `PlatformAdapter` 接口（start/stop/sendGroup/sendPrivate/isOnline/status），然后在 `manager.ts` 的 `startAll()` 中按环境变量启用即可，核心引擎无需改动。
